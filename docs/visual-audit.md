## Remaining verification

The overlay endpoints are confirmed black85% and17%. Top-dark/bottom-light is visually observed, so CSS uses180deg and0%/100%; those angle/positions were not exposed numerically. Crop mode was not exposed; existing object-fit:cover/center is retained without claiming a source defect. The reference is a vector, not an icon font. Export was unavailable; the basic two-bar plus is authored here and introduces no third-party icon dependency/license. Live covers differ from the historical mockup; equivalent deterministic fixtures are required before claiming crop/overlay equivalence. Full-page screenshot candidates are generated for QA to compare with the Figma before baseline approval. Generation/replay alone does not establish fidelity. Independent QA accepted the corrected platform baselines; these source limitations prevent an absolute pixel-perfect claim.

`text-box: trim-both cap alphabetic` is applied progressively under `@supports`; controlled line-box fallbacks preserve readable layout on older browsers. Tests wait for `document.fonts.ready` before measuring or capturing. Content flows naturally and the footer reaches the viewport bottom for short pages; the fixed Figma frameheight is not copied into the application.

Brand ANIME rich-text fill was not exposed separately; using the Warning#ffb800 shared yellow is a visual inference (that hex is authenticated on load-more). Icon fill#fff and29.82×24 slot are authenticated; two-bar shape is reconstructed and passed independent zoom comparison.
