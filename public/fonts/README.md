# Mulish font assets

`mulish-latin-wght-normal.woff2` is the unmodified normal variable Latin font from `@fontsource-variable/mulish` **5.3.0**, downloaded from the npm registry. Its weight axis covers 200–1000, including the authenticated Figma Regular 400 and Semibold 600 styles. This file is served locally; no runtime font CDN is required.

- [Fontsource installation and provenance](https://fontsource.org/fonts/mulish/install)
- [Upstream Mulish project](https://github.com/googlefonts/mulish)
- Package archive: `https://registry.npmjs.org/@fontsource-variable/mulish/-/mulish-5.3.0.tgz`
- SHA-256: `8d1d33d6beea5a722b8f336d79c61c07405949457e37b5e65454c72dc10aba1a`
- License: [SIL Open Font License 1.1](OFL-Mulish.txt), included with its attribution unchanged.

The Latin subset includes Portuguese accented Latin-1 letters. Non-Latin live anime titles may use the system sans-serif fallback; no separate non-Latin font is bundled.
